## 🚀 Installation & Setup  

1️⃣ **Clone the repository:**  
   ```sh
   git clone https://github.com/Yogasastha/my-portfolio.git
   cd my-portfolio

2️⃣ Install dependencies:

  npm install
3️⃣ Run the project locally:

  npm start
4️⃣ Build for production:

  npm run build
